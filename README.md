论文研读助手是一款适用于 Windows 的本地论文阅读与笔记软件，面向需要精读论文、整理文献综述和积累研究笔记的学生与研究者。它将 PDF 原文、结构化阅读卡、批注和文献比较整合在同一个工作台中，帮助你理清论文的研究问题、证据链和结论边界，留下可以回看、核对与复用的阅读记录。

阅读与记录可离线使用，AI 参考分析按需启用；支持连接本机模型或自行配置的外部 API，也支持将阅读记录同步到本地 Obsidian 笔记库。

**当前版本：1.3.8 · Windows 10/11 x64 · EXE 安装版 · 基础功能离线可用**

## 下载与安装

安装文件：`论文研读助手-1.3.8-安装程序.exe`。

### 系统要求

- Windows 10 或 Windows 11，64 位系统。
- 可写的安装目录，以及用于显示工作界面的浏览器。
- 安装程序自带 Python 运行环境与 PDF.js，无需额外安装 Python。
- PDF 阅读、批注和阅读卡不依赖 AI 服务；AI 分析需另行配置本机模型或外部 API。

### 安装步骤

1. 下载并双击 `论文研读助手-1.3.8-安装程序.exe`。
2. 按安装向导选择安装位置，可使用默认目录，也可选择 `D:\论文研读助手` 等可写目录。
3. 按需要选择是否创建桌面快捷方式，完成安装。
4. 在安装结束时选择立即启动，或从开始菜单、桌面快捷方式打开“论文研读助手”。
5. 软件会在默认浏览器中打开本地工作台，地址通常为 `http://127.0.0.1:8765`。点击“导入 PDF”开始阅读。

默认按当前用户安装，无需管理员权限。选择全体用户安装时可能需要管理员权限。若默认端口已被占用，软件会自动选择其他可用端口。

**首次运行提示**：1.3.8 安装程序尚未进行代码签名，Windows 可能显示 SmartScreen 提示。确认文件来自你认可的发布来源后，可在提示中选择“更多信息 → 仍要运行”。

### 启动与退出

安装后通过开始菜单或桌面快捷方式启动软件。界面显示在浏览器中，PDF 处理和数据保存由本机服务完成。

退出时请点击软件中的“保存并退出软件”。直接关闭浏览器标签页不会停止后台服务；再次打开快捷方式可回到工作台。

## 核心功能

### PDF 原文与阅读记录并排呈现

- 支持批量导入 PDF，单个文件最大 80 MB。
- 提供整页适配、宽度适配、缩放与页码跳转。
- 原文与记录栏可拖拽调整宽度，左侧文献栏与右侧记录栏可分别收起。
- 支持按标题、作者和主题搜索，以及在读、完成、归档状态筛选。
- 导入时在本机尝试提取标题、作者、年份、来源与 DOI；识别不到的字段留空，也可手动校正。

### 四步研读与结构化阅读卡

将阅读过程组织为四个阶段，让每一篇论文都留下问题、依据与自己的理解。

| 阶段 | 阅读重点 | 记录内容 |
| --- | --- | --- |
| 定位问题 | 作者研究什么，为什么值得研究？ | 研究问题、文献缺口、主要回答与贡献 |
| 拆解证据 | 方法与证据如何支持结论？ | 数据与样本、概念与变量、研究方法、核心结果 |
| 形成判断 | 结论有多可靠，在哪些条件下成立？ | 稳健性、替代解释、适用边界、自己的疑问 |
| 复述与应用 | 能否独立复述，并连接到后续研究？ | 独立复述、文献联系、下一步行动 |

阅读卡涵盖 13 个记录字段，并针对框架与综述、因果与机制实证、描述与趋势实证、理论模型提供不同的阅读提示。

### 批注、术语与原文定位

- 选中 PDF 文本即可添加批注，也可手动记录当前页的想法。
- 支持论点、证据、疑问、术语四类批注。
- 将原文摘录与自己的理解分开保存，并记录页码。
- 支持设置文内页码偏移，区分 PDF 页码与论文印刷页码。

### 文献比较与 Markdown 导出

- 按研究问题、数据与方法、主要结果、结论边界、研究联系并列表格，辅助整理综述线索。
- 支持按主题或作者筛选比较范围。
- 阅读卡与文献比较表可导出为 Markdown，便于继续整理和复用。

### Obsidian 笔记库同步

- 将阅读卡、批注与 PDF 原文附件同步到本地 Obsidian 笔记库的专用文件夹。
- 支持保存记录时自动同步，也可手动同步全部文献。
- 同步时保留笔记中的“我的补充”及自动生成区域之外的内容。
- 删除软件内的论文不会删除已经同步到 Obsidian 的笔记与附件。

### 可选的 AI 参考分析

- 支持 Ollama、LM Studio，以及使用 HTTPS 的 OpenAI 兼容接口。
- 按阅读卡结构生成参考分析，与自己的阅读记录分开呈现。
- 对模型返回的证据引文进行原文核对，并标注需要人工确认的内容。
- 长论文超过单次输入预算时自动分段处理，记录实际送入模型的页范围。
- 支持暂停 AI 请求与取消任务；默认不启用导入后自动排队生成。
- 可选读图与图表分析，需支持图片输入的模型与接口，以及本机可用的 Poppler 渲染工具。

AI 参考用于辅助理解与核对。研究判断、引文使用和最终结论仍需回到原文确认。

### 本地备份与迁移

- 文献库默认保存在软件目录下的 `data/`。
- 支持导出完整 ZIP 备份，包含 PDF 原文、阅读卡、批注、AI 分析结果与抽取缓存。
- 恢复备份时补入当前库缺少的文献，保留已有同编号记录。
- 也可在退出软件后复制 `data/`，迁移到另一份软件副本。

## 开始研读

1. **导入论文**：点击“导入 PDF”，选择一篇或多篇论文，并核对自动提取的文献信息。
2. **记录理解**：按四步研读填写阅读卡，在原文中标出论点、证据、疑问和术语。
3. **整理文献联系**：进入“文献比较”，对照不同论文的问题、方法、结果和边界。
4. **保存与复用**：导出 Markdown 阅读卡或比较表，也可连接 Obsidian 笔记库持续同步。

## 配置 AI 参考分析（可选）

在“设置与 Obsidian 同步”中选择连接方式、Provider、模型名称与接口地址。使用本机模型前，请先启动对应的模型服务。

外部 API 的密钥通过环境变量提供；软件设置中只填写环境变量名，不填写密钥值。完成环境变量设置后，重启软件，再对需要分析的论文发起生成请求。

图表分析需额外准备可通过 `PATH` 找到的 `pdftocairo` 或 `pdftoppm`，并使用支持图片输入的接口，例如 LM Studio 或其他 OpenAI 兼容接口。当前 Ollama 自有协议适配器不发送图片；缺少渲染工具时，分析会继续以文字输入进行。

## 数据、升级与卸载

### 数据保存位置

文献库保存在**安装目录下的 `data/`**，例如安装到 `D:\论文研读助手` 时，数据目录为 `D:\论文研读助手\data`。

| 位置 | 内容 |
| --- | --- |
| `data/library.json` | 文献信息、阅读卡、批注和设置 |
| `data/papers/` | 导入的 PDF 原文 |
| `data/analyses/` | AI 参考分析结果 |
| `data/extracted/` | 原文抽取缓存 |

更换安装目录不会自动迁移原文献库。需要迁移时，可在设置中导出并恢复完整备份，或退出软件后复制 `data/` 到新安装目录。

### 升级

1. 在设置中导出完整备份。
2. 使用“保存并退出软件”停止当前实例。
3. 运行新版本安装程序，选择原安装目录进行升级。

1.3.8 安装程序的覆盖安装策略会保留 `data/` 和 `run/`，已有文献库不会被新的空库替换。软件当前不提供自动更新。

### 卸载

从开始菜单选择“卸载 论文研读助手”，或通过 Windows 的应用管理页面卸载。

**卸载默认保留文献库。** 只有在卸载过程中明确选择删除数据，才会连同 PDF 原文、阅读记录和 AI 结果一起移除。保留数据后，重新安装到同一目录可继续使用原文献库。

## 数据与隐私

- **本地保存**：PDF 原文、阅读记录、设置和 AI 分析结果保存在软件目录下的 `data/`。
- **离线阅读**：不启用 AI 时，阅读与记录无需向模型服务发送论文内容。
- **按需使用模型**：默认不自动生成 AI 分析；主动生成或自行启用自动排队后，内容会发送给你配置的模型服务。
- **本机模型**：连接本机回环地址上的模型服务时，论文内容不出本机。
- **外部接口**：使用远程模型服务时，分析所需的论文文本及启用读图后选中的页面图片会发送到该服务，留存与计费取决于服务商。
- **密钥管理**：密钥在运行时从环境变量读取，不写入文献库、备份、日志或导出文件。
- **无遥测**：软件不包含遥测功能。

## 当前范围与限制

- 当前发行版支持 Windows 10/11 x64，尚未提供 macOS 版本。
- 扫描件可以人工阅读和记录，但没有文本层时不能直接生成 AI 参考分析；当前未提供内置 OCR。
- 文献信息提取属于有限范围的自动识别，仍需人工核对。
- 长论文分析受输入与请求预算限制，实际覆盖范围以阅读卡中的“输入范围”为准。
- 图表分析依赖多模态模型、兼容接口与本机渲染工具。
- 当前没有独立的公式解析与推导功能，也不支持自动更新。

## 技术实现

采用 Python 3.12 标准库后端、原生 HTML/CSS/JavaScript 前端与 PDF.js 阅读组件，通过本机服务在浏览器中提供工作界面。安装版包含运行所需的 Python 环境与 PDF.js 资源。

## 常见问题

**为什么安装后打开的是浏览器？**

浏览器是软件的工作界面，本机服务负责处理 PDF 和保存记录；基础阅读功能可以离线使用。

**必须配置 AI 才能使用吗？**

无需配置 AI 即可导入论文、阅读、批注、填写阅读卡、比较文献和导出笔记。AI 参考分析为可选功能。

**能把软件安装到 D 盘吗？**

可以。在安装向导的“选择安装位置”中选择 D 盘的可写文件夹即可，文献库也会保存在该安装目录中。

**为什么关闭浏览器后软件还在运行？**

关闭标签页不会结束本机服务。需要彻底退出时，请使用软件内的“保存并退出软件”。

**升级或卸载会删除论文吗？**

1.3.8 的覆盖安装保留文献库，卸载也默认保留数据；卸载时明确选择删除数据才会移除文献库。升级与迁移前可使用完整备份留存一份副本。
