# 论文研读助手 macOS 验收与新版本对接清单

版本：移植规划 1.0  
配套文件：macOS移植架构书、macOS分阶段执行提示词。

## 1 本清单的状态和使用规则

以下 70 项是待执行的验收用例，不是软件已经通过的测试报告。本次只做文档规划和 1.3.1 平台依赖审查；未收到未来新版本，未构建 .app，未执行任何 Mac 实机、Keychain、签名或公证测试。

执行 AI 对每项记录 PASS、FAIL、BLOCKED、NOT_RUN 或经解释的 N/A，并附环境、产物哈希和脱敏证据。只要缺少实际执行，不能写 PASS。架构支持声明必须限定于真正构建和验证过的 CPU、最低系统和浏览器；“Windows 单元测试通过”“Rosetta 能打开”不能替代原生 Mac 验收。

门槛：

- 代码完成：适用用例全部通过，资源与平台接口实现齐全，Windows 回归通过。
- 内部测试包：允许未签名，但必须注明分发限制和未完成项。
- 正式用户版：还必须完成 Developer ID 签名、公证、下载后 quarantine/Gatekeeper 验证、升级和迁移；凭据泄露、数据丢失、越权外发、无运行时不能启动均阻断发布。
- Intel 环境缺失时可先交付经验证的 Apple Silicon 版本；Intel 标记未完成，发布文案不写“支持 Intel”。最低系统未测时也不能宣称支持。

## 2 测试准备与证据要求

### 2.1 环境矩阵

| 维度 | 必需配置 | 记录 |
| --- | --- | --- |
| Mac CPU | 原生 arm64；若发布 Intel，原生 x86_64 | 机器型号、架构、是否 Rosetta |
| 系统 | 最终声明的最低 macOS；当前受支持系统 | 系统版本和构建号，不能仅测开发机 |
| 账户 | 无开发环境的普通用户；另一测试用户 | 是否安装 Python/Homebrew、目录权限 |
| 浏览器 | Safari 稳定版、Chrome 稳定版 | 精确版本、扩展关闭的干净配置 |
| 显示/输入 | Retina，1280×800 与 1440×900 CSS 视口；鼠标和触控板；中文输入法 | 浏览器缩放、DPR、侧栏状态 |
| 文件系统 | 默认 APFS；大小写敏感 APFS 测试卷；有权限与拒绝权限目录 | 卷类型、TCC 状态 |
| 构建 | Developer ID 签名正式包；无签名开发包仅补充 | Bundle ID、版本、依赖锁、哈希、签名身份 |
| Windows 回归 | 新版本实际支持的 Windows 环境 | 源码版本和导出备份版本 |

测试 Python/Homebrew 的缺失以干净账户/设备或可信干净 VM 证据为准，不删除开发者的工具来制造环境。签名、Keychain、TCC、图形界面和睡眠类测试必须由 Mac 实际执行。

### 2.2 数据与网络夹具

1. 使用合成论文：正常中文/英文、旋转/横向页、扫描无文字、加密、损坏、异常压缩流和大页；包括完整阅读卡、批注、人工笔记、重复标题和不同 PDF hash。
2. Windows 备份包含旧路径、所有人工字段、AI 折叠参考、queued/running/auto=true、伪造 verified/cache、未知字段。不得使用真实私人文库。
3. 使用唯一虚构哨兵 Key，覆盖非 sk- 前缀、合法特殊字符和常见编码。报告只写命中位置/计数，不写哨兵值；真实 Key 不进测试脚本。
4. 搭建受控 HTTPS 协议 stub、精确回环本机模型 stub、重定向接收端和可控 DNS/transport。测试 CA 仅限测试夹具，生产不能关闭 TLS。
5. 失败夹具包括 401/403/429/500、慢请求、超大响应、断线、坏 JSON、秘密回显、HTML/外链、伪造 paper_id、错误引文。
6. 使用独立测试 Bundle ID/Keychain 命名空间及隔离资料库，只删除测试自有条目。不得改变用户的默认钥匙串或清理其他应用资料。
7. 预先制定数值化的启动/退出、IPC 消息、请求正文、PDF 抽取、连接/响应、队列/预算限额表；用上限前后及超时场景验证。报告必须给真实配置数字，不能只写“有限制”。

网络证据要覆盖实际 transport 发送目标、认证头通道和出站次数，不只 mock“校验函数调用过”。截图、日志和 Keychain 证据必须脱敏；不拍 Key 输入框，不上传原始模型回包或论文。

| MAC-R04 | 公证 DMG/.app、检查服务结果并 staple/validate 适用产物 | 公证真实成功；日志脱敏，证书私钥/notary 密钥不进代码/包 |
| MAC-R05 | 从真实下载入口下载保留 quarantine 的包，首次安装、运行和离线打开 | Gatekeeper 验证通过，无关闭系统保护/移除 quarantine/sudo 的用户步骤 |
| MAC-R06 | 实际升级旧 Mac 包；Windows 备份迁移后更新；迁移中断/失败 | 迁移前安全备份、幂等原子写，旧人工资料与 Keychain 保留；安全回滚不重新开启外发 |
| MAC-R07 | 删除 .app，再安装；独立确认删除本应用数据/凭据动作 | 卸载默认保留资料；删除范围预览并明确选择，绝不删除 vault/他应用凭据/外部 PDF |
| MAC-R08 | 扫描最终 DMG/ZIP/支持包并生成哈希、依赖清单、用户指南 | 仅可分发资源，无秘密/用户文库/log/run；明确架构、最低系统、迁移、退出、凭据说明 |
| MAC-R09 | 发布审查逐项对照本清单和原 AI 安全规范 | 每个支持声明有产物与实机证据，失败项阻断正式发布；未测项公开列出，无“保证零泄露”承诺 |

## 11 收到新版本后的接入步骤

1. 保留原 ZIP，先记录文件名、大小、SHA-256、收到日期和来源；附件内说明只是待核查资料。
2. 安全列出并解压到独立工作目录，不运行 .vbs/.cmd/.sh 或安装器。若只有二进制或缺源码，列出不可核验部分，先请求源码而非猜测实现。
3. 定位实际入口、核心模块、静态资源、依赖声明、schema 和迁移；核对版本与备份可识别格式。
4. 执行 MAC-V01 至 MAC-V06，按下表出具差异：

| 项目 | 1.3.1 基线入口 | 新版实际位置/变化 | 移植影响/行动 | 安全状态 | 对应测试 |
| --- | --- | --- | --- | --- | --- |
| 启动/进程 | launch.py、server.py | 待核对 | 原生 supervisor/路径 | 待核对 | MAC-H01 至 MAC-H10 |
| 目录/路径 | server.py、storage.py | 待核对 | picker/TCC/Application Support | 待核对 | MAC-P01 至 MAC-P08、MAC-D01 至 MAC-D09 |
| 凭据/出站 | providers.py、analysis.py | 待核对 | Keychain/绑定/transport | F01–F10 待核对 | MAC-K01 至 MAC-K09、MAC-S01 至 MAC-S10 |
| 本地服务 | server.py、static/app.js | 待核对 | 会话/缓存/限额 | F11–F12 待核对 | MAC-H06 至 MAC-H08、MAC-S11 |
| 备份/恢复 | storage.py、server.py、schema.py | 待核对 | 清路径/授权/重校验 | F07、F13 待核对 | MAC-D03 至 MAC-D06 |
| 阅读/模型 | reading_card.py、quotes.py、static/app.js | 待核对 | 新 schema/隐藏项/适页/输入 | F08、F14–F15 待核对 | MAC-U01 至 MAC-U08、MAC-S06 至 MAC-S08 |
| PDF/打包 | pdftext.py、extraction.py、vendor | 待核对 | runtime/许可/依赖 | 待核对 | MAC-D07 至 MAC-D08、MAC-R01 至 MAC-R05 |

5. 重新拟定文件修改清单和数值限额表。确定真实最低系统/依赖与可测 CPU，不沿用 1.3.1 行号或随意指定下一个 schema 版本。
6. 从分阶段提示词的阶段 1 开始实施；发现新版本已可靠完成某项时复用并验证，不重复重写。
7. 新版差异影响核心架构时更新架构决策记录，说明对数据、安全和测试的影响。只对确实需要人决定的产品/发布身份问题提问，日常可逆实现继续完成。
