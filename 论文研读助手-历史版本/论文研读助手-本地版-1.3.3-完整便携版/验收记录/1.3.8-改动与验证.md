## 一、收起控件移到左侧、与侧栏一体

**做法**
- 收起控件从顶栏右侧移入**侧栏顶部品牌行**（`#toggle-sidebar`，圆形箭头按钮，与 `.brand` 同一行）——即"与侧栏一块"。
- 新增 `.main` 左缘的**常驻把手** `#sidebar-rail`：它绝对定位在 `.main` 上，因此展开时正好贴住侧栏接缝（x = 侧栏右缘）、收起后停在窗口最左缘（x = 0）。没有它，侧栏一隐藏按钮就跟着消失、没有入口可展开。
- 两个入口共用同一份状态（`paper-reader:sidebar-collapsed`），`applySidebar()` 同时更新两处的 `aria-pressed`/`aria-expanded`/箭头/标题。

**验证（真实浏览器，1500×950）**

| 状态 | 把手 x | 侧栏右缘 | 贴缝 | 正文起点 | 工作区宽度 |
|---|---|---|---|---|---|
| 展开 | 238 | 238 | `at_seam: true` | — | 1230px |
| 收起 | 0 | — | 停在最左 | x=0 | **1468px**（两栏仍左右并排） |

契约测试 `tests/test_layout_contract.py::SidebarCollapse` 增加 2 项：控件必须在 `<aside class="sidebar">` 内且不在顶栏、把手存在且 `aria-controls="sidebar"`、两个入口写入同一状态。

## 二、删除 AI 进度条的填充块

**做法**：删掉三处填充块，只保留阶段名 + 百分比 + 服务端消息。
1. `index.html` 阅读带上 `#ai-progress` 里的 `.ai-progress-track/#ai-progress-fill`；
2. `app.js` 阅读卡面板 `aiProgressHTML()` 里的进度条与 `#ai-progress-fill.style.width` 赋值；
3. `app.js` 文献栏行内的 `.mini-progress.ai` 小条（点击分析时多出来的"图标"）。
CSS 里 6 条 `.mini-progress.ai` / `.ai-progress-track` / `.ai-progress-fill` 规则一并删除；**四步研读进度条（`.progress-track`/`#progress-bar`）不是 AI 的，保留**。

**验证**：`live_ui_check.py` 对在用实例回报 `progress_fill_removed: true`；测试新增 `test_the_progress_fill_block_is_gone`（断言 HTML/JS/CSS 里都没有 `ai-progress-fill`/`ai-progress-track`，同时断言四步研读进度条仍在）。

## 三、EXE 安装程序（可选安装目录）

**做法**
- 用 **Inno Setup 6.7.3**（`winget install JRSoftware.InnoSetup`，按用户安装）；脚本 `installer/论文研读助手.iss`，图标由 `tools/make_icon.py`（Pillow）生成 `installer/icon.ico`（多尺寸，同侧栏"研"标记）。
- 关键设置：`PrivilegesRequired=lowest`（免管理员；`{autopf}` 解析为 `%LOCALAPPDATA%\Programs`，**安装目录可写**，因此文献库继续放在 `{app}\data`，不需要迁移）、`DisableDirPage=no`（**保留目录选择页**）、开始菜单快捷方式 + 可选桌面快捷方式、自带卸载器、`CloseApplications=yes`。
- **升级与卸载安全**：`data\` 与 `run\` 排除在覆盖范围外；`data\library.json` 用 `onlyifdoesntexist uninsneveruninstall` 写入，因此覆盖安装不会覆盖读者的库；卸载默认**保留** `data\`，只有在卸载最后一步明确回答"是"才删除。
- 构建脚本 `tools/build_installer.py`：刷新便携暂存树 → 调 `ISCC.exe` → 输出安装程序与 SHA256。

**验证（`tests/verify_installer.py`，真实静默安装/卸载）**

| 检查 | 结果 |
|---|---|
| 静默安装（`/VERYSILENT /DIR=临时目录`） | 退出码 0；启动器、runtime、空库、卸载器、图标均在；**未带 `tests`/`installer`/`tools`** |
| 安装后启动（用快捷方式同一个 `.vbs`） | 健康检查 `version: 1.3.8`，端口落在 **8766**（你的实例占着 8765，端口自动错开） |
| 优雅停止 + 静默卸载 | 退出码 0 |
| 卸载后 | 程序文件已删除；**`data\library.json` 与测试标记文件都被保留** |

产物：`论文研读助手-1.3.8-安装程序.exe`（12 885 484 字节，SHA256 `aff2e06fe5549d154ef5aac030fdd0b17367cccdd5aca243a149dce0182083c4`）。
