## 三、一分钟验收路径

```bat
cd /d "D:\harness home\paper-reader"

REM 1. 全量测试（约 9 分钟，276 项）
python -m unittest discover -s tests -v

REM 2. 一体化验收（服务端 + 浏览器，约 1.5 分钟）
python -m unittest discover -s tests -p "test_acceptance.py"
python -m unittest discover -s tests -p "test_acceptance_browser.py"

REM 3. 三窗口截图与布局数字
python tests/capture_acceptance_shots.py
python tests/measure_layout.py --label after

REM 4. 重新生成样例分析文件与交付文档
python tests/capture_phase8_samples.py
python tests/build_delivery_docs.py --run-tests
```

界面人工验收：

1. 双击启动文件打开软件（默认端口 8765），确认左侧文献列表与阅读区正常。
2. 打开"设置与 Obsidian 同步"，确认"AI 参考分析"区块显示 Provider 状态与四条说明。
3. 打开一篇论文 → 切到"阅读卡" → 确认每个栏目先显示人工内容，右侧有"查看 AI 参考"。
4. 点击任一"查看 AI 参考"：只展开该栏目，显示答案、置信度、"PDF 第 N 页"按钮与短引文。
5. 点击"PDF 第 N 页"回到原文；滚轮上下翻页；按 ←/→ 翻页；关闭再打开，确认回到上次页码。

## 四、尚未完成 / 需你决定的事项

1. **线上安装目录仍是 v1**：改造全部在 `D:\harness home\paper-reader`。要上线需要你确认切换方式
   （直接替换目录 / 先在另一台机器验证 / 保留旧目录改名）。
2. **样例分析文件的措辞来自测试夹具**：引文、页码与 `verification` 都是真实的，答案句子用于演示
   格式。接上你自己的本机模型后，界面里看到的会是该模型的措辞。
3. **`terms` / `reader_questions` / `warnings` 尚未在界面展示**（已在答案文件里）。
4. **跨天使用前的性能预期**：1000 篇以上的库首次加载会变慢（前端一次性拉取 `/api/state`）。
5. **未在 macOS / Linux 验证**；未在 4K 显示器或触屏设备上做人工视觉检查。
