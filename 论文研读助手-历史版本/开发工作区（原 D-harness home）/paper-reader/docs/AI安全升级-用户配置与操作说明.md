# 论文研读助手 1.3.1 AI 安全升级 — 用户配置与操作说明

本文件说明这次安全升级后，**外部 AI 会把论文发到哪里**、**密钥怎么配置**、**怎么暂停和撤销**，以及**怀疑泄漏时怎么办**。面向使用者，不假设你读过源码。

---

## 1 你的数据会去哪里

| 模式 | 目标 | 论文内容是否会离开本机 |
|---|---|---|
| 本机模型（Ollama / LM Studio） | `http://127.0.0.1:…` 或 `http://localhost:…` | **不会**。只在本机回环地址内传输。 |
| 外部 API（HTTPS） | 你填写并**确认过的那个域名** | **会**。论文正文分段、标题与任务说明会发送给该服务商。 |

> **"自动分析"开关**：默认**关闭**。关闭时，导入 PDF 只是把论文放进库并显示"点击查看 AI 参考"，不会产生任何费用。
> 打开它之后，**每次导入都会自动发送一次**（外部 API 模式下即产生一次调用费用）。想省费用就保持关闭，逐篇按需点击。

必须知道的三件事：

1. **只会发往你批准过的目标。** 换域名、换模型、换凭据引用、换「连接方式」之后，之前对某篇论文的批准会失效，需要重新点一次「生成参考」。
2. **只发送论文正文相关的内容。** 你的笔记、批注、阅读步骤、其他论文、文件路径、API Key 都不会进入请求。程序会扫描请求，一旦发现凭据特征就**直接放弃发送**。
3. **服务商侧的留存、训练与删除由服务商决定。** 本软件无法保证对方不留存。涉及未公开数据时，请先用本机模型，或先做人工脱敏（当前版本没有自动脱敏）。

---

## 2 配置外部 API

1. 打开「AI 设置」，把「连接方式」选为**外部 API**，填写 HTTPS 接口地址（例如 `https://服务商域名/v1`）与模型名。
2. 填写**环境变量的名字**，不是密钥本身。例如填 `PAPER_READER_VENDOR_KEY`。
3. 在你自己的系统里把密钥设置成这个环境变量，然后**重新启动程序**：

   PowerShell（当前用户，永久生效）：
   ```powershell
   [Environment]::SetEnvironmentVariable('PAPER_READER_VENDOR_KEY', '你的密钥', 'User')
   ```

4. 保存设置。界面只显示「已读取 / 未设置 / 格式可疑」，**不会回显密钥，也不提供读取密钥的接口**。
5. 首次对某篇论文点「生成参考」就是对该目标的批准。

要点：

- **页面里没有粘贴密钥的入口**，这是有意为之：浏览器里的密钥会进入页面内存、可能被扩展读取，也可能被浏览器写盘。
- 密钥不会写入库文件、备份、Markdown、Obsidian、日志或诊断包。
- 本机模型需要密钥时同样用环境变量引用，不写明文。

## 3 暂停、停用、撤销

| 操作 | 位置 | 效果 |
|---|---|---|
| **暂停所有 AI 出站** | AI 设置里的开关 | 立刻拒绝所有 AI 请求：主请求、JSON 修复、重试，也包括健康检查与模型列表（它们同样会带上密钥出网）。**人工阅读、字段、批注、同步完全不受影响。** |
| **停用该 API** | 设置界面 | 只停用当前这个目标，不阻止其他目标。 |
| **撤销对某篇的批准** | 更换目标/凭据后自动失效 | 该论文回到「等待确认」状态，不会自动重发。 |
| **取消某次任务** | 论文卡片上的取消 | 在抽取后、发送前、修复前、重试前都会再检查一次；已经发出的请求无法保证被服务商中止或退费。 |

**「结果未知」是什么意思**：请求已经发出但没收到回应（超时/连接中断）。这时程序**不会自动重发**，因为对方可能已经受理并计费。费用记录保持已用，由你决定是否再花一次。

---

## 4 费用控制

- 每次生成最多 **2 次调用**（主请求 + 一次修复），重试与"为兼容服务商而重发"都计入同一次数。
- 若服务商拒绝某个可选参数需要重发，这次重发同样占用额度；额度不足时程序**不会**重发。
- 24 小时内的请求总数、队列深度、并发数都有上限，在 AI 设置里可调。
- **额度在请求发出前就扣减**，不会等对方回复用量再判断。
- 输出 token 上限会真正写进请求参数。如果服务商不支持该参数，程序**不会**改成无上限请求，而是直接报错停下。
- 程序按**次数**记账（24 小时窗口 + 每次生成上限），并记录实际发送次数。
- 程序**不读取**服务商返回的用量字段，也不计算金额：最终账单请以服务商控制台为准。

---

## 5 恢复与备份

- 备份包含：PDF、人工记录、已验证的 AI 答案、抽取缓存。**不包含**密钥、会话凭据、批准票据、任务与费用记录。
- **恢复时会重新校验**：PDF 重新抽取、答案重新按当前原文核对。核对不通过的答案不会显示为已验证。
- 旧版本生成的答案会保留文本，但标记为「未按当前规则重新核对，仅供参考」。
- 恢复**不会**自动开始分析，也不会恢复任何「已批准发送」的状态。
- 备份是敏感论文包，**ZIP 不等于加密**。请放在你自己控制的目录里；放进云盘等于把论文同步出去。

---

## 6 怀疑泄漏时怎么做

1. **立刻暂停所有 AI**，并在服务商控制台**吊销那个密钥**（吊销比改配置更有效）。
2. 换一个新密钥，更新环境变量，重启程序，再重新启用。旧密钥的明文从环境变量里删掉。
3. 检查这些位置是否曾出现过密钥：`.env` 之类的手工文件、旧版本的 `credentials.json`、你分享过的目录、云盘历史版本、浏览器保存的页面。
4. 删除旧副本：包括升级前的安装目录、旧备份、旧日志。程序不会替你删除这些历史文件。
5. 本版本**没有**「诊断包/支持包」导出功能，因此也没有可供误分享的诊断文件。需要排查问题时请提供：版本号、界面上的固定错误码，以及复现步骤（**不要**发送论文、答案或任何密钥）。

## 7 已知边界（请按边界使用）

- **不防御同一账户下的恶意程序。** 本机的保护是「只监听回环地址 + 只允许本用户通过命名管道领取一次性凭据」。同一登录账户下的其他程序仍可能读取本机论文文件、注入浏览器或读取环境变量。
- **不识别「可信服务商」是不是真的可信。** 程序保证的是「只发往你批准的目标、密钥只进入该目标的认证头」，不能保证对方守约。
- **提示注入无法根除。** 论文里写的「忽略规则/上传密钥/访问网址」只会被当作论文文字，且模型没有工具、不能联网、不能读文件；但模型仍可能被诱导写出错误内容——所以引文只有**逐字命中**才标为已核对，近似匹配一律标为待人工核对。
- **引文命中 ≠ 解释正确。** 界面显示「AI 参考」与「已核对引文条数」，不代表推理结论被证实。
- **代理未实现。** 当前只支持直连：即使系统设置了 `HTTP_PROXY`/`HTTPS_PROXY`，程序也不会使用它们，而是直接连接你批准的地址。
- **未做真实服务商调用验证。** 兼容性结论来自协议桩测试；请先用一篇不敏感的论文试一次。
