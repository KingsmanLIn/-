# 论文研读助手-本地版 1.3.1 发布说明

发布日期：2026-10-11

## 这一版新增了什么

### 1. PDF 阅读区改为"优先整页"并支持滚轮翻页
- 打开论文时先按"适合页面"计算；若这样会把正文缩到看不清（1366×768 及更小的屏幕），
  自动改用"适合宽度"（正文由 4 px 提升到约 11 px）并在页码下方提示一次。窗口放大到
  1920×1080 及以上会自动切回整页显示。你自己选过缩放下拉后，软件不再自动切换。
- 鼠标在 PDF 区域内滚动即可翻页：一次手势只翻一页，翻页后约 0.6 秒内不连续翻动；
  第一页与最后一页不会越界，也不会把整个页面外壳滚走。放大后先滚动页面内容，
  到上/下边界才翻页。
- `←` / `→`、工具条按钮、页码输入框照常可用；页码变化会写进阅读进度，下次打开回到这一页。

### 2. AI 参考分析（可选，默认关闭）
- 为阅读卡的 13 个栏目生成一份**参考**：默认不显示、不请求；只有你点"查看 AI 参考"才生成。
- 每个栏目都带 PDF 物理页码与逐字短引文，软件会先到原文核对引文；核对不通过的内容
  不会展示，整份参考也不会标成"已就绪"。
- 支持本机 Ollama、LM Studio 以及其他 OpenAI 兼容接口。论文原文默认不出本机；
  改成外部地址时请自行确认对方政策。
- 密钥只从系统环境变量读取，不写入文献库、备份、日志或页面。
- 参考内容只写在单独的分析文件里，**永远不会**覆盖你的阅读卡、步骤或批注；
  想引用时必须点"复制到该栏目"（追加，不覆盖）。

### 3. 原文区成为主角（本版重点）
- 顶部只留一行信息与一行进度条：标题条由 80px 压到 26px、顶栏 65→48px、进度条 39→29px，
  上方占用从 346px 降到 245px。1366×768 下原文可视高度由 396px 增到 **525px**。
- 工具条右上角新增 **收起记录栏**：收起后原文区占满整个宽度，正文由约 11px 增大到约 17px；
  再点一次展开，选择会被记住。收起期间记录照常保存，只是暂不显示。
- 小屏上若"整页显示"会把正文缩到看不清，软件自动改用"适合宽度"并提示；判断阈值已按新的
  可用高度调整（0.62 → 0.78），窗口放大到 1920×1080 以上自动切回整页显示。

### 4. 其他改进
- 长论文如果超出单次请求的字数预算，参考里会写明"本次只送入第 X–Y 页"，不再静默截断。
- 参考文件丢失或原文变化时状态会变成"需要重新生成"，并提供"生成 / 重试"按钮。
- 上游模型服务的报错只保留首行 120 字并脱敏后才记进库里。

## 安装 / 升级步骤

1. 关闭正在运行的旧版（或先在旧版里点"保存并退出软件"）。
2. 把压缩包解压到一个**新文件夹**（不要直接覆盖旧文件夹，方便回退）。
3. 双击 **启动论文研读助手.vbs**（需要已安装 Python 3.10+；也可双击"备用启动.cmd"查看错误）。
4. 第一次启动会自动把旧格式的文献库升级到 v2 格式：你的阅读卡、阅读步骤、批注和上次页码
   **原样保留**，升级前的原始文件会备份为 `data/library.previous.json`。
5. 把旧的 `data\papers` 文件夹里的 PDF 复制到新文件夹的 `data\papers`（升级包已包含）。

## 从 1.1 升级与回滚

- 升级不改动 `data\papers` 里的 PDF，也不改动你的 `fields`、`steps`、`annotations`。
- 回滚：直接用旧文件夹重新启动即可；旧版本会忽略新增的 `analysis` 字段。
- 想彻底清理 AI 痕迹：删除 `data\analyses` 与 `data\extracted` 两个目录。

## 启动问题修复（1.3.1）

- **同一文献库被两个进程打开时不再崩溃**：以前第二个实例会在 data/instance.lock 上抛
  PermissionError，界面只显示“启动失败”。现在会检测到已有实例，直接打开它；
  如果占端口的是**另一个目录的旧版本**，会弹窗说明它在哪里、怎么退出。
- **启动失败一定看得到原因**：错误会写入 
un/startup.log 并在弹窗里给出最后一行，
  不再只有一句“启动失败”。
- **弹窗不再卡住启动**：之前的提示框是阻塞式的，无人点确定时启动流程会一直等；
  现在提示框由独立进程显示。
- 想彻底重来：关掉所有实例（设置页“保存并退出软件”），必要时删除 
un/startup.log。

## 已知限制

- 扫描件（纯图片 PDF）不做 OCR：参考分析会返回"原文未说明"，阅读、批注与阅读卡照常可用。
- 需要自备本机模型，建议 7B 以上的中文指令模型；小模型常因输出不合 JSON 而失败。
- 长论文：单次请求预算为中文约 28 000 字 / 英文约 36 000 字，超出部分会写明未送入。
- 耗时：20–40 页论文用 7B 量化模型约 30 秒–10 分钟（取决于是否用 GPU），一次只处理一篇。
- 环境：已在 Windows + Python 3.13 + Chrome 验证，未在 macOS / Linux 测试。

## 文件校验

压缩包内附 `SHA256.txt`，可用 `certutil -hashfile <文件> SHA256` 核对。
