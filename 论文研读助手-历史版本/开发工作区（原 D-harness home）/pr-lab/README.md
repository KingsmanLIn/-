# 论文研读助手

一个**完全在本机运行**的 Windows 论文阅读工具：PDF 阅读 + 你自己的四步阅读卡与批注 + 可选的 AI 参考分析（只有你点击时才把论文发送给你自己配置的模型服务，本机模型或外部 HTTPS 接口）。纯 Python 3.12 标准库 + 原生 HTML/CSS/JS，自带 Python 运行时与 PDF.js，不联网也能阅读与记录。

当前版本 **1.3.8**。

## 特性

- **本机运行，无遥测**：界面由本机服务提供（`http://127.0.0.1:8765` 起），数据都在软件目录的 `data/` 里。
- **PDF 阅读**：整页适配 / 宽度适配 / 放大，滚轮逐页切换；原文与记录栏之间可拖拽调整宽度，双击恢复默认（原文约 58% / 记录栏约 42%）。
- **导入即填元数据**：导入时在本机解析首页，自动填入作者、年份、来源、DOI、引用条目；**只填空字段**，识别不到就留空，不猜测。带期刊版头/封面页的英文论文（Elsevier/ScienceDirect、Wiley 等）会先剥离版头再找标题，并从版头取刊名、卷期与出版年。
- **四步阅读卡与批注**：定位问题 → 拆解证据 → 形成判断 → 复述与应用；选中原文即可建批注（论点/证据/疑问/术语）。可导出阅读卡，也可同步到本地 Obsidian 笔记库（同步位置 `笔记库 / 论文研读助手`）。
- **左侧控件台可收起**：收起按钮在**侧栏顶部**（与侧栏一体），另有一条**常驻把手**在阅读区左缘——展开时贴在侧栏接缝，收起后停在窗口最左侧；状态记住。
- **记录栏可收起**：收起后原文独占整宽。
- **AI 参考分析（可选）**：支持本机模型（Ollama / LM Studio，论文不出本机）与你自己指定的外部 HTTPS 接口；首次发送即视为批准，目标变化后需重新点一次生成。
- **密钥只从环境变量读**：页面里只填**变量名**（需以 `PAPER_READER_` 开头，或使用常见服务商名如 `OPENAI_API_KEY`）；密钥不写入文献库、备份、日志、页面或导出文件。
- **进度显示**：阶段名（排队中/抽取原文/切分原文/请求模型/校验内容/保存结果/完成）+ 百分比 + 服务端消息；长论文显示「正在读第 X/Y 段（PDF 第 A–B 页）」。1.3.8 起不再绘制进度填充块，只保留这些文字信息。
- **读图与图表分析（可选，默认关闭）**：把带图表/图片的页面在**本机**渲染成 PNG，随请求一起发送给同一个模型服务（需要多模态模型）；可限制页数（0–8，默认 4）。本机缺少 poppler 的 `pdftocairo`/`pdftoppm` 时只是少发图片，任务照常。
- **长论文分段续读**：超出单次输入预算时自动分段（英文约 36 000 字符/段、中文约 28 000 字符/段），最多 3 段 + 1 次修复；卡片「输入范围」写明实际送入的页范围与段数。
- **失败码清楚**：`output_truncated`、`reasoning_only`、`credential_missing`、`invalid_response`、`quote_missing` 等给出固定错误码与处理建议；回答不是合法 JSON 时同段严格重发一次，字段级修复只重发有问题的字段。
- **删除与清理**：文献栏每行有删除控件，也会标出「原文缺失」的记录；删除会级联清理这篇的 PDF、AI 答案、抽取缓存与任务记录，**不动**你的 Obsidian 笔记库；删除前写库快照。
- **备份 / 恢复 / 迁移**：设置区导出完整备份（含原文、阅读卡、批注、已验证的 AI 答案），也可直接复制 `data/` 目录。
- **多副本并存**：端口独占绑定并自动错开（8765、8766…），各自使用自己的文献库。
- **完整性清单**：随包提供 `SHA256.txt`。

## 快速开始

### Windows 便携版（免安装）

1. 下载并解压便携 zip 到**可写**位置（整个文件夹一起放）。
2. 双击 **`启动论文研读助手.vbs`**（系统禁用脚本时用 `启动（备用）.bat`）。
3. 浏览器会自动打开 `http://127.0.0.1:8765`。
4. 退出：在页面里点 **「保存并退出软件」**（直接关浏览器标签不会停止软件）。

### Windows 安装程序

发行版同时提供 `论文研读助手-1.3.8-安装程序.exe`：

- 按**当前用户**安装（不需要管理员权限），也允许改成全体用户安装；
- **可以选择安装目录**；
- 创建开始菜单快捷方式（桌面快捷方式可选，安装完可勾选立即启动）；
- 自带卸载器；**卸载默认保留文献库 `data\`**，只有卸载时明确选择「是」才会一起删除（默认按钮是「否」）；
- 覆盖安装不会动 `data\` 与 `run\`，升级安全；
- 安装程序**没有代码签名**，首次运行可能出现 SmartScreen 提示（「更多信息 → 仍要运行」）。

## 隐私与安全

- **本机运行**：论文、阅读记录与 AI 答案都存在软件目录的 `data/`；软件不含遥测，不会把内容发往你配置之外的任何地方。
- **密钥只从环境变量读**：页面里只填变量名；密钥值不写入文献库、备份、日志、页面或导出文件，也不回显、不缓存、不回传。

  ```powershell
  [Environment]::SetEnvironmentVariable('PAPER_READER_KEY', '你的密钥', 'User')
  ```

  设置后需要重启软件。
- **只在你点击后发送**：不点「生成 AI 参考」就没有任何出站请求；本机模型（Ollama / LM Studio）默认在回环地址运行，论文原文不出本机；如果你把地址改成外部服务器或第三方兼容接口，原文会发送到该地址，请自行确认对方的隐私与留存政策。
- **不动你的笔记库**：删除与同步都不会改动 Obsidian 笔记库里的笔记与附件。
- **删除有快照**：删除前把当前库写入 `data/library.previous.json`，误删可回滚。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击启动文件似乎没反应 | 先看浏览器是否已经打开了**另一个副本**的页面（端口号不同）；多个副本可并存 |
| 换了新版本，按钮点了没反应 | 1.3.4 起静态文件已改为每次校验（`?v=1.3.8`）；若仍异常，按 `Ctrl + F5` 强制刷新一次 |
| 安装时出现 SmartScreen 蓝框 | 安装程序没有代码签名：点「更多信息 → 仍要运行」 |
| 卸载后发现文献库还在 | 这是有意设计：卸载默认保留 `data\`；要删就手动删除该目录，或卸载时选择「是」 |
| 导入后作者/年份为空 | 该 PDF 首页没有可识别信息（扫描件常见）；解析只读前 3 页，填不上就手动填写 |
| 提示输出被截断（`output_truncated`） | 提高「输出上限」或换用非推理型模型；带图读长论文时保持 32768 |
| 打开了读图但答案里没有图的内容 | 模型不是多模态，或本机没有 poppler 的 `pdftocairo`/`pdftoppm`；此时只会少发图片，任务照常 |

## 开发者

### 目录结构

```
pr-lab/
├─ server.py          本机 HTTP 服务与路由（含会话、CSRF、静态资源版本号）
├─ launch.py          启动器：探测已有实例、选端口、拉起服务、打开浏览器
├─ analysis.py        AI 分析任务编排（分段、额度、重试、修复）
├─ reading_card.py    阅读卡提示词、结构校验与修复模板
├─ providers.py       模型适配器（ollama / lmstudio / openai_compatible、多模态载荷）
├─ figures.py         图表页选页与本机渲染（poppler）
├─ pdftext.py         PDF 文本抽取（pdftotext → 内置解析器 → pypdf）
├─ metadata.py        首页元数据解析（版头剥离、标题/作者/年/来源/DOI）
├─ storage.py         文献库读写与级联删除
├─ schema.py          设置与记录的结构、默认值与范围
├─ job_policy.py      审批、额度与队列策略
├─ backup_guard.py    备份/恢复范围与保留策略
├─ static/            界面：index.html + app.js + 各 CSS
├─ vendor/            PDF.js（本地副本）
├─ runtime/           自带的 Python 3.12 运行时
├─ docs/              使用说明与计划文档；docs/images/ 截图
├─ installer/         Inno Setup 脚本与图标
├─ tools/             build_installer.py、make_icon.py
├─ tests/             离线测试与打包/验证脚本
├─ data/              文献库（library.json、papers/、analyses/、extracted/）
├─ run/               端口与日志（server.json、startup.log）
└─ SHA256.txt         完整性清单
```

### 常用命令

以下命令都在 `pr-lab` 目录下执行（`runtime\python.exe` 是包内自带的运行时）：

```powershell
:: 离线测试（注入假模型与临时目录，不联网、不计费）——当前 211 项通过
runtime\python.exe -B -m unittest discover -s tests

:: 前端语法检查
node --check static\app.js

:: 打包便携 zip（结束后打印 SHA256）
runtime\python.exe tests\build_package.py
:: 校验包：解压 → 包自带 Python 核对 SHA256.txt → 真实启动 → 停止
runtime\python.exe tests\verify_package.py

:: 构建 Windows 安装程序（需要 Inno Setup 6 的 ISCC.exe；图标由 make_icon.py 生成，需要 Pillow）
runtime\python.exe tools\build_installer.py
```

构建安装程序的前置条件：本机已安装 Inno Setup 6（`ISCC.exe`，路径在 `tools/build_installer.py` 里配置），且 `installer/icon.ico` 已由 `tools/make_icon.py` 生成（该脚本需要 Pillow）。
