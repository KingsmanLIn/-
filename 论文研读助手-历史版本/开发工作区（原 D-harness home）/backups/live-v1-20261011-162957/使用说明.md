# 论文研读助手

一个可离线使用的本地论文阅读工作台。原文、阅读步骤、批注和阅读卡放在一起，适合刚开始阅读经济学论文的研究生。

## 打开软件

双击本文件夹中的 **启动论文研读助手.vbs**。软件会在默认浏览器中打开。不需要网络、账户或 API 密钥；当前电脑已具备所需的 Python 环境。如果系统禁用 VBS，可双击 **备用启动.cmd**。

整个文件夹可以搬到其他位置，启动文件会根据所在位置打开。换到另一台电脑时，需要安装 Python 3.10 或以上版本；无需安装额外 Python 库。请使用 Chrome 或 Edge 等现代浏览器。

## 第一次使用

1. 左侧已放入你提供的三篇论文。点击一篇即可开始，也可以导入新 PDF。
2. 查看“文献信息”，核对作者、年份、来源、论文类型与页码。新导入的论文不会自动猜测这些信息。
3. 按“定位问题—拆解证据—形成判断—复述与应用”填写。完成本步记录后再勾选确认。
4. 拖选原文文字，点击“选中文字 → 添加批注”。原句、自己的理解和页码分开保存。也可以直接记录本页图表、公式或疑问。
5. 在“阅读卡”汇总记录；在“文献比较”按问题、方法、结果和边界比较文献。

阅读提示会随论文类型和语言调整。预置论文另有针对其实际内容的引导、术语和跳页入口。确认步骤表示完成了一轮理解练习，不代表软件已经判断结论正确。

## 连接 Obsidian

1. 打开“设置与 Obsidian 同步”。
2. 点击“浏览”，选择你的本地 Obsidian 笔记库文件夹；也可直接填写路径。
3. 勾选“保存记录时，自动同步到 Obsidian”，保存设置。
4. 软件会在笔记库中建立 **论文研读助手** 文件夹，包含文献索引、Markdown 阅读卡和“附件”子文件夹。索引会自动汇总比较记录；批注带有 PDF 页码链接，点击可回到原文。

这是 **软件记录到本地 Obsidian 文件夹的单向同步**，不依赖 Obsidian Sync 付费服务。Obsidian 自己的设备同步可以继续使用。软件运行且自动同步开启时，每次保存都会更新生成区域。

在 Obsidian 中自由写作，请使用阅读卡底部的 **我的补充**，或自动区域之外的位置。软件更新会保留这些内容及你添加的属性。自动区域以内的阅读卡内容请在本软件中修改。同步前一版本会存放在笔记库专用目录的“.同步备份”中。

如果修改或删除了自动区域标记，软件会停止覆盖该笔记并显示提示；本地阅读记录仍可保存。恢复标记后点击“立即同步全部文献”。尚未选择笔记库时，可以先导出 Markdown 后放入 Obsidian。

## 数据与备份

- 软件数据保存在本软件文件夹的 **data** 中；请保留整个文件夹。
- 本地每次保存使用完整文件替换，并保留前一版 `library.previous.json`。
- 定期在设置中点击“导出完整备份”。ZIP 包含 PDF、记录与 Markdown 阅读卡。
- “恢复备份”会添加当前库缺少的文献，保留已有同编号记录；不会恢复旧的同步目录或自动开启同步。
- PDF 文字高亮是软件中的独立批注记录；原文文件不嵌入新批注。扫描件可以阅读图片并手动记录，软件不含 OCR。
- “导出阅读卡”生成单篇 Markdown；“下载原文”可保存相应 PDF。完整备份内的 Markdown 与 PDF 保持相对链接。开启 Obsidian 同步时会自动带上原文附件。

## 常用操作

- Ctrl + S：立即保存。
- 在批注框中 Ctrl + Enter：保存批注。
- 未输入文字时，左右方向键：翻页。
- 关闭浏览器后服务仍运行；重新双击启动文件可再次打开。
- 需要完全退出时，点击设置中的“保存并退出软件”。

## 使用边界

软件提供阅读引导和记录，不自动代写研究判断、翻译全文或生成可靠性评分；学习结果需要自己回到原文核对。它可以与 Zotero 配合：Zotero 管理正式条目和写作引用，这里管理阅读过程。

目前为本地单用户工具。两个窗口同时修改同一篇文献时会提示冲突并保留浏览器草稿，避免直接覆盖；可从设置中导出草稿后手动合并。

## 第三方组件

PDF 显示使用 Mozilla PDF.js 5.6.205，采用 Apache License 2.0。许可证位于 `vendor/pdfjs/LICENSE`。应用无需连接外部服务，内置论文仅供你的本地阅读使用。
