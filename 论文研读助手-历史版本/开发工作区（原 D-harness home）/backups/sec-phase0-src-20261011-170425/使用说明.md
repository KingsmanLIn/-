# 论文研读助手

一个可离线使用的本地论文阅读工作台。原文、阅读步骤、批注和阅读卡放在一起，适合刚开始阅读经济学论文的研究生。

## 打开软件

双击本文件夹中的 **启动论文研读助手.vbs**。软件会在默认浏览器中打开。不需要网络、账户或 API 密钥；当前电脑已具备所需的 Python 环境。如果系统禁用 VBS，可双击 **备用启动.cmd**。

整个文件夹可以搬到其他位置，启动文件会根据所在位置打开。换到另一台电脑时，需要安装 Python 3.10 或以上版本；无需安装额外 Python 库。请使用 Chrome 或 Edge 等现代浏览器。

## 第一次使用

1. 左侧已放入你提供的三篇论文。点击一篇即可开始，也可以导入新 PDF。
2. 查看“文献信息”，核对作者、年份、来源、论文类型与页码。新导入的论文不会自动猜测这些信息。
3. 按“定位问题—拆解证据—形成判断—复述与应用”填写。完成本步记录后再勾选确认。
4. 拖选原文文字，点击“选中文字 → 添加批注”。原句、自己的理解和页码分开保存。也可以直接记录本页图表、公式或疑问。
5. 在“阅读卡”汇总记录；在“文献比较”按问题、方法、结果和边界比较文献。

阅读提示会随论文类型和语言调整。预置论文另有针对其实际内容的引导、术语和跳页入口。确认步骤表示完成了一轮理解练习，不代表软件已经判断结论正确。

## 阅读区的翻页与缩放

### 原文区是主角

- 顶部只保留一行信息（标题、作者、标签、按钮）与一行进度条，其余高度全部留给原文。
- 工具条右上角有 **收起记录栏**：收起后右侧"阅读步骤/批注/阅读卡"整栏隐藏，原文区占满
  整个宽度（1366×768 下正文从约 11 px 增大到约 17 px）。再点一次 **展开记录栏** 即可回来，
  你的选择会被记住；收起期间记录仍在保存，只是暂时不显示。
- 窄屏（窗口宽度 ≤930px）仍是上下布局：原文在上、记录在下，收起按钮不参与布局。

### 缩放与翻页

- **默认优先整页显示**：打开论文时先按"适合页面"计算。若这个缩放会把正文缩到看不清
  （约 1366×768 及更小的屏幕会出现），软件会自动改用"适合宽度"并在页码下方提示一次；
  把窗口放大到 1920×1080 左右会自动切回"适合页面"。你自己选过缩放下拉之后，软件不再自动切换。
- **整页可见时**：页面不会在同页内滚动——滚轮向上/向下就是翻页。
- **滚轮翻页**：一次手势只翻一页，翻页后约半秒内不会连续翻动（避免触控板一滑就跳好几页）；
  第一页和最后一页不会越界，也不会把整个页面外壳滚走。
- **放大之后（"适合宽度" / 125% / 150%）**：页面会超出阅读区，此时滚轮先滚动页面内容，
  滚到上/下边界后下一次手势才翻页。
- **其他翻页方式**：工具条上的 `‹` `›` 按钮、页码输入框、键盘 `←` / `→` 都可用；页码变化会
  同时更新页脚"PDF 第 N 页 · 文内 X"并写入阅读进度，下次打开自动回到这一页。
- **不会误触**：按住 Ctrl 滚动（缩放手势）、在输入框/弹窗内滚动、拖选文字时的滚动都不会翻页。
- 鼠标停在右侧笔记栏上滚动只会滚动笔记内容，不会翻页。

## 已知限制（详见 docs/已知限制.md）

- **扫描件没有文本层**：本工具不做 OCR，纯图片 PDF 的参考分析会全部返回"原文未说明"，
  阅读、批注与阅读卡仍可正常使用。
- **需要自备本机模型**：建议 7B 以上的中文指令模型；小模型常因输出不合 JSON 而失败。
- **长论文耗时**：20–40 页论文用 7B 量化模型约 30 秒–10 分钟（取决于是否用 GPU）；
  软件一次只处理一篇，其余排队。
- **长论文可能只分析前一部分**：单次请求有字数预算（中文约 28 000 字、英文约 36 000 字），
  超出部分不会送入模型。此时参考里会明确写出"本次只送入第 X–Y 页"，相关栏目显示
  "原文未说明"；请在阅读卡里以原文为准补齐。

## AI 参考分析（可选，默认关闭）

软件可以调用**本机**模型，为阅读卡的 13 个栏目生成一份“参考分析”。它不会替你填写阅读卡：参考内容单独保存，只有你点击“查看 AI 参考”才会显示，也永远不会写入你自己的 `fields`、阅读步骤或批注。

1. 打开“设置与 Obsidian 同步”，找到“AI 参考分析（可选）”。
2. 选择 Provider：`Ollama`（默认 `http://127.0.0.1:11434`）或 `LM Studio`（默认 `http://127.0.0.1:1234/v1`，也兼容其他 OpenAI 兼容接口），填写**模型名称**（例如 `qwen2.5:7b`）。
3. 保存设置后，状态行会显示 Provider 是否可用、以及当前加载了哪些模型。
4. 打开一篇论文，点击“查看 AI 参考”开始生成；生成期间可以继续阅读、写批注和阅读卡。

**未配置 Provider 时**：导入新论文后照常阅读、批注、填写阅读卡，只是该论文的 AI 状态显示为“等待配置本地模型”，不会有任何请求发出。

**数据边界**：Ollama 与 LM Studio 默认只在本机回环地址运行，论文原文不出本机。如果你把接口地址改成外部服务器或第三方兼容接口，论文原文会发送到该地址，请自行确认对方的隐私与留存政策。

**密钥**：软件只保存**环境变量的名字**（例如 `OLLAMA_API_KEY`），密钥本身从系统环境变量读取，不会写入文献库、备份、日志或页面。若没有密钥（本机模型通常不需要），留空即可。

**强制重跑**：原文、提示词版本、模型与语言都没变化时，已生成的参考不会重复请求模型。点击“重新生成”会再次占用本机模型算力与时间（每篇约数十秒到数分钟，取决于模型大小与页数），使用外部接口还可能产生调用费用。

**可信度**：每个字段都带 PDF 物理页码与逐字短引文，软件会先到原文核对引文；核对不通过的引文不会展示，整份参考也不会显示。AI 内容属于参考，学习判断仍需回到原文核对。

## 连接 Obsidian

1. 打开“设置与 Obsidian 同步”。
2. 点击“浏览”，选择你的本地 Obsidian 笔记库文件夹；也可直接填写路径。
3. 勾选“保存记录时，自动同步到 Obsidian”，保存设置。
4. 软件会在笔记库中建立 **论文研读助手** 文件夹，包含文献索引、Markdown 阅读卡和“附件”子文件夹。索引会自动汇总比较记录；批注带有 PDF 页码链接，点击可回到原文。

这是 **软件记录到本地 Obsidian 文件夹的单向同步**，不依赖 Obsidian Sync 付费服务。Obsidian 自己的设备同步可以继续使用。软件运行且自动同步开启时，每次保存都会更新生成区域。

在 Obsidian 中自由写作，请使用阅读卡底部的 **我的补充**，或自动区域之外的位置。软件更新会保留这些内容及你添加的属性。自动区域以内的阅读卡内容请在本软件中修改。同步前一版本会存放在笔记库专用目录的“.同步备份”中。

如果修改或删除了自动区域标记，软件会停止覆盖该笔记并显示提示；本地阅读记录仍可保存。恢复标记后点击“立即同步全部文献”。尚未选择笔记库时，可以先导出 Markdown 后放入 Obsidian。

## 数据与备份

- 软件数据保存在本软件文件夹的 **data** 中；请保留整个文件夹。
- 本地每次保存使用完整文件替换，并保留前一版 `library.previous.json`。
- 定期在设置中点击“导出完整备份”。ZIP 包含 PDF、记录与 Markdown 阅读卡。
- “恢复备份”会添加当前库缺少的文献，保留已有同编号记录；不会恢复旧的同步目录或自动开启同步。
- PDF 文字高亮是软件中的独立批注记录；原文文件不嵌入新批注。扫描件可以阅读图片并手动记录，软件不含 OCR。
- “导出阅读卡”生成单篇 Markdown；“下载原文”可保存相应 PDF。完整备份内的 Markdown 与 PDF 保持相对链接。开启 Obsidian 同步时会自动带上原文附件。

## 常用操作

- Ctrl + S：立即保存。
- 在批注框中 Ctrl + Enter：保存批注。
- 未输入文字时，左右方向键：翻页。
- 关闭浏览器后服务仍运行；重新双击启动文件可再次打开。
- 需要完全退出时，点击设置中的“保存并退出软件”。

## 使用边界

软件提供阅读引导和记录，不自动代写研究判断、翻译全文或生成可靠性评分；学习结果需要自己回到原文核对。它可以与 Zotero 配合：Zotero 管理正式条目和写作引用，这里管理阅读过程。

目前为本地单用户工具。两个窗口同时修改同一篇文献时会提示冲突并保留浏览器草稿，避免直接覆盖；可从设置中导出草稿后手动合并。

## 第三方组件

PDF 显示使用 Mozilla PDF.js 5.6.205，采用 Apache License 2.0。许可证位于 `vendor/pdfjs/LICENSE`。应用无需连接外部服务，内置论文仅供你的本地阅读使用。
