# 论文研读助手 1.3.8 更新说明

## 新增

- **Windows 安装程序**（`论文研读助手-1.3.8-安装程序.exe`）：可自选安装目录、创建开始菜单快捷方式、可选桌面快捷方式、自带卸载器；按当前用户安装，不需要管理员权限。
- **应用图标**：安装程序、开始菜单与桌面快捷方式使用与软件内一致的「研」字标记。
- **阅读区左缘的常驻把手**：收起控件台后仍可从这里展开。
- **安装/卸载冒烟测试**（`tests/verify_installer.py`）：静默安装 → 启动 → 检查版本与端口 → 卸载 → 确认文献库保留。
- **统一使用说明** `docs/使用说明.md`（根目录 `使用说明.md` 与其内容一致）。
- **`README.md`**：可直接作为 GitHub 项目说明（简介、特性、快速开始、隐私与安全、开发者命令、路线图）。
- **`CHANGELOG.md`**：1.3.3 → 1.3.8 的完整变更时间线。
- **`发布索引.md`**：各版本产物清单与 SHA256 校验值。

## 修改

- **收起控件台的位置**：收起/展开控件从窗口顶栏右侧移到**左侧控件台的顶部品牌行**，与控件台成为一体；两个入口（侧栏内按钮、左缘把手）共用同一状态，刷新后保持。
- **AI 分析进度显示**：由「进度条 + 文字」改为**纯文字**——保留阶段名、百分比与服务端消息（长论文仍显示「正在读第 X/Y 段（PDF 第 A–B 页）」）。
- **安装与升级方式**：除便携压缩包外，新增安装程序方式；覆盖安装不会改动 `data\` 文献库，卸载默认保留文献库（卸载时可选择删除）。
- **交付脚本**（内部）：改为安全覆盖，不再整目录删除重建，永不触碰 `data\` 与 `run\`。
- **打包能力**（内部）：新增 `tools/build_installer.py` 与 `installer/论文研读助手.iss`，可在一条命令内产出便携包与安装程序。

## 移除

- **AI 分析进度的填充块**：删除了阅读带上与阅读卡面板里的进度填充条，以及左侧文献栏行内的细进度条。
  四步研读进度条不受影响，仍然保留。

## 修复

- 无（1.3.8 未包含缺陷修复；此前的修复见 `CHANGELOG.md` 中 1.3.7 及更早的条目）。

## 未包含
