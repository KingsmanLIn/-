# 论文研读助手 1.3.4 使用说明

本软件是一个**完全在本机运行**的论文阅读工具：PDF 阅读 + 你自己的阅读卡与批注 + 可选的 AI 参考分析（只有你主动点击时，才会把论文发送给你自己配置的模型服务）。所有数据都保存在本文件夹里。

---

## 一、第一次启动

1. 把**整个文件夹**放在可写的位置（例如桌面或 D 盘），不要只复制其中某个文件。
2. 双击 **`启动论文研读助手.vbs`**。若系统禁用脚本，双击 **`启动（备用）.bat`**。
3. 软件会在默认浏览器打开，地址形如 `http://127.0.0.1:8765`。
4. 退出：在页面里点 **「保存并退出软件」**（直接关浏览器标签不会停止软件）。

---

## 二、目录结构

| 目录 / 文件 | 作用 |
|---|---|
| `runtime/` | 自带的 Python 3.12 运行时，**不要删除或移动** |
| `vendor/` | PDF.js，用于在页面里渲染 PDF |
| `static/` | 界面文件（HTML/CSS/JS） |
| `data/` | **你的文献库**：`library.json`（记录）、`papers/`（PDF）、`analyses/`（AI 参考答案）、`extracted/`（原文抽取缓存） |
| `run/` | 运行状态与日志：`server.json`（端口与进程号）、`startup.log`（事件日志） |
| `验收记录/`、`版本说明.md` | 本版本的改动与验证记录 |
| `SHA256.txt` | 文件完整性清单（除自身外覆盖包内全部文件） |

---

## 三、启动与多实例（重要）

- 同一个软件可以有**多个副本同时运行**：每个副本用自己的 `data/`，端口会**自动错开**（8765、8766、8767…），互不影响。
- 双击**同一个副本**的启动文件不会重复启动，只会打开已在运行的那个页面。
- 地址栏里的端口号就是实例标识：`8765` 是第一个启动的副本，`8766` 是第二个，以此类推。
- 想让某个副本停止：在**它的页面**里点「保存并退出软件」。
- 更新版本后**不需要清理浏览器缓存**：界面脚本已改为每次校验，总是加载最新版本。

---

## 四、导入论文

- 点 **「＋ 导入 PDF」**，可多选；单个文件上限 80 MB。
- 导入时会**在本地解析首页并自动填入作者、年份、来源、DOI、引用条目**：
  - 只填空字段，**不会覆盖你已经填写或修改过的内容**；
  - 识别不到就留空，**不猜测**（扫描件没有文本层时跳过填充，不影响导入）；
  - 这次解析同时生成原文缓存，后续 AI 分析会直接复用，不再重复读取 PDF。
- 导入后可在「文献信息」里核对并修改，点保存。

---

## 五、阅读与记录

- 默认整页适配，滚轮逐页切换；可在右下角切换宽度适配或放大。
- 左侧「文献栏」可搜索、可切换 **全部 / 归档**。
- 右侧是四步阅读卡与批注；底部显示「N / 4 已确认」的完成度。
- 在原文里选中文字，可直接建批注（论点/证据/疑问/术语）。

## 六、AI 参考分析

### 1. 配置（页面底部「AI 设置」）

| 项目 | 说明 |
|---|---|
| 连接方式 | `本机模型`（Ollama / LM Studio，论文不出本机）或 `外部 API`（HTTPS，需密钥） |
| Provider | `ollama` / `lmstudio` / `openai_compatible` |
| 模型名称 | 服务商提供的模型标识 |
| 接口地址 | 本机可留空用默认；外部 API 必须填最终 HTTPS 地址 |
| 密钥环境变量名 | **只填变量名**，例如 `PAPER_READER_KEY`。名字需以 `PAPER_READER_` 开头，或使用已知服务商名（`OPENAI_API_KEY`、`DEEPSEEK_API_KEY` 等）。**不要把密钥填进页面** |
| 输出上限 | 默认 16384（范围 256–32768）。推理型模型会先占满推理，出现截断错误时请提高 |

在 Windows 里设置环境变量（当前用户，永久生效），**然后重启软件**：

```powershell
[Environment]::SetEnvironmentVariable('PAPER_READER_KEY', '你的密钥', 'User')
```

### 2. 生成与批准

- 对某篇论文点「生成 AI 参考」。**首次发送即视为你批准了这个目标**；更换地址、模型、凭据引用或输出上限后，需要重新点一次生成。
- 可以随时「暂停所有 AI 出站」或取消当前任务。

### 3. 进度条（本版新增）

生成时会在论文处显示**进度条 + 阶段**，一眼看出进行到哪一步：

```
排队中 → 抽取原文 → 切分原文 → 请求模型 → 校验内容 → 保存结果 → 完成
  0%       15%         30%         55%         80%         95%      100%
```

- 长论文会显示 **「正在读第 X/Y 段（PDF 第 A–B 页）」**；
- 文献栏对应那一行也会有一条细进度条，不打开论文也能看到进度；
- 完成后显示「参考分析已就绪（13 个字段，N 条引文已核对…）」，失败时显示具体原因。

### 4. 长论文的读取范围与费用

- 论文超过单次输入预算时会**自动分段续读**：每段尽量占满预算，下一段接着上一段，最后一版卡片是完整结果。
- 每篇最多 **3 段 + 1 次修复**（最多 4 次传输）；能在 1 段内读完的论文仍然只需 1 次调用。
- 卡片里的「输入范围」会写明**实际送入模型的页范围与段数**（例如「已分 3 段全部送入模型」）。
- 每篇任务、24 小时窗口、输出 Token 与队列都有额度上限，可在设置里查看。

### 5. 失败码对照

| 显示 | 含义与处理 |
|---|---|
| `output_truncated` | 输出被上限截断（推理型模型常见）→ 提高输出上限或更换模型 |
| `reasoning_only` | 模型只产出推理、没有正式答案 → 同上 |
| `credential_missing` | 没读到密钥：变量名未设置或为空 → 设置后**重启软件** |
| `credential_not_bound` | 这个连接还没绑定密钥引用（设置里没填变量名） |
| `credential_invalid` | 密钥值不合法（含首尾空格/控制字符/过长） |
| `auth_error` | 服务商拒绝了这个凭据（401/403） |
| `unreachable` / `timeout` | 连不上或响应超时；本机模型请确认服务在运行 |
| `consent_required` | 这篇还没有批准：点一次「生成 AI 参考」即可 |
| `invalid_response` | 返回内容没通过结构校验；可重试一次，仍失败建议换模型 |

## 七、删除论文（含清理残留记录）

**两个入口**：① 左侧**文献栏每一行右侧的删除控件**；② 打开论文后在操作区的「删除论文」。两者都会先弹出确认框（写入论文标题）。

- **会删除**：这篇的 PDF、AI 参考答案、失败记录、原文抽取缓存，以及任务与审批记录。
- **不会删除**：你 Obsidian 笔记库里的笔记与附件（软件从不改动笔记库）。
- 删除前会把当前库写入 `data/library.previous.json`，误删可用它回滚。
- 如果你在资源管理器里手工删过 `data/papers/` 里的 PDF，文献栏会标出 **「原文缺失」**；用同一入口删除该记录即可清理干净。

## 八、备份、恢复与迁移到另一份副本

- **导出备份**：设置区「导出备份」得到一个 zip（含 PDF、人工记录、已验证的 AI 答案、抽取缓存；**不含**密钥、任务与额度记录）。
- **恢复备份**：在新副本/新电脑里用「恢复备份」导入。
- 也可以**直接复制 `data/` 目录**完成迁移：先退出软件，复制 `data/` 到新副本同名位置，再启动。

---

## 九、安全与边界

- 密钥**只在运行时从环境变量读取**，不写入文献库、备份、日志、页面或导出文件；事件日志是固定字段白名单。
- 论文内容**只在你点击生成后**发送给你配置的那个地址；软件不会把内容发往别处，也不含遥测。
- 删除、同步都不会改动你的 Obsidian 笔记库。
- 服务商侧的留存与计费由服务商决定；未公开材料建议只用本机模型。

## 十、完整性校验（可选）

```powershell
cd "解压后的目录"
Get-Content SHA256.txt | ForEach-Object {
  $hash, $rel = $_ -split '  ', 2
  if ((Get-FileHash -LiteralPath $rel -Algorithm SHA256).Hash.ToLower() -ne $hash) { "不一致: $rel" }
}
"校验完成"
```

## 十一、常见问题

| 现象 | 处理 |
|---|---|
| 双击启动文件似乎没反应 | 先看浏览器是否已经打开了**另一个副本**的页面（端口号不同）；本版两个副本可并存 |
| 提示「端口被另一个论文研读助手占用」 | 说明该端口已被占用且本副本未能启动；退出另一个实例（在它的页面点「保存并退出软件」）后重试 |
| 页面按钮点了没反应 | 本版已修复静态缓存问题；若仍异常，按 `Ctrl + F5` 强制刷新一次 |
| 导入后作者/年份为空 | 该 PDF 首页没有可识别信息（扫描件常见），手动填写即可 |
| 打开 PDF 是空白/乱码 | 扫描件没有文本层：可人工阅读，AI 参考不可用 |
| 答案里出现「原文未说明」 | 该字段在送入的页范围内确实没有依据；「输入范围」里写了送入的页 |
| 生成的提示说被截断 | 提高「输出上限」，或换用非推理型模型 |
| 想彻底停掉软件 | 在页面里点「保存并退出软件」；必要时在任务管理器结束 `pythonw.exe` |
